# 本地历法与五行合参

## 目标是"零输入门槛"，不是"完整命理"

真正的八字合盘要四柱（年月日时），用户往往不知道对方出生的具体时辰。要求对方填时辰，多数人直接放弃。

**所以这里的定位是：只要双方出生年月日，就能给出一层可信的五行参考。** 这在产品上成立，但必须在界面上说清它是"简化参考"，不能宣称是完整八字合婚——这是个诚实性问题，也是免责的前提。

## 用 lunar-javascript 本地算

MIT、零依赖、UMD 格式，浏览器直接引入：

```html
<script src="assets/js/vendor/lunar.js"></script>
```

核心调用链（`Solar` 是公历，`Lunar` 是农历）：

```js
// 1. 公历 → 农历
const solar = Solar.fromYmd(1990, 5, 20);
const lunar = solar.getLunar();

// 2. 取八字（四柱）
const ec = lunar.getEightChar();
const dayGan = ec.getDayGan();   // 日柱天干 = 日主

// 3. 天干 → 五行
const element = WUXING.gan[dayGan];   // '乙' → '木'
```

也有 `Solar.fromDate(new Date())`，适合直接取当前时间。注意传入的日期应是**用户的真实出生日期**，不要做时区转换——用户填的就是当地的出生日期。

## 判定两人关系

以"我"（甲方日主）与"对方"（乙方日主）比较，五种关系：

```js
function relation(a, b) {           // a=我, b=对方
  if (a === b) return '比和';
  if (WUXING.sheng[a] === b) return '我生';   // 我去生对方
  if (WUXING.sheng[b] === a) return '生我';   // 对方来生我
  if (WUXING.ke[a] === b)    return '我克';
  if (WUXING.ke[b] === a)    return '克我';
  return '无直接关系';
}
```

各关系的合作含义：

| 关系 | 合作解读 | 加分 |
|---|---|---|
| 比和（同属性） | 步调容易一致，但缺互补，容易一起犯同样的错 | +4 |
| 生我 | 对方给你资源与支持，你是受益方 | +3 |
| 我生 | 你投入多、托举对方，需留意回报 | +3 |
| 我克 | 你主导节奏，能推动但易压迫对方 | -2 |
| 克我 | 对方强势，你压力大，需设边界 | -2 |

## 已验证的实际输出

用真实日期跑过，可作回归基准：

| 出生日期 | 日柱 | 日主五行 |
|---|---|---|
| 1990-05-20 | 乙酉 | 木 |
| 1988-11-03 | 壬戌 | 水 |

木与水的关系判为 **生我**（水生木），即对方来生我。改动历法库或映射表后，用这两组数据回归验证。

## 五行性格与合作风格

给每种五行写四段文案，直接决定这段解读有没有用：

```js
'木': {
  name: '木', core: '生长、进取、开拓',
  style: '像树木一样向上生长，擅长开创新局、提出新想法。',
  coop:  '合作中你是开拓型角色，适合负责方向与创意。注意别过度理想化，落地需要务实伙伴补位。',
  warn:  '易急于扩张，根基未稳就想要长大。'
}
```

`coop` 是合作场景专用，`warn` 是该五行的短板提醒。**两者都要有**——只说优点像拍马屁，只说缺点让人不适，一优一劣才像真在分析。

## 与塔罗结果的合并

五行只做**加权**，不主导总分（否则用户会觉得"塔罗白抽了"）：

```js
if (wuxingResult && wuxingResult.relationType) {
  score += wuxingBonus(wuxingResult.relationType);  // 见上表 +4/+3/-2
}
score = Math.max(5, Math.min(95, Math.round(score)));
```

同时界面上要**分区展示**：塔罗六段解读归塔罗，五行合参单独一块，最后才是综合结论。混在一起会让用户分不清哪句话来自哪里。

## 允许留空

对方生日常常问不到。设计上必须支持：

- 两个生日都可空 → 只出塔罗解读，五行区块整体隐藏
- 只填一方 → 不做合参，提示"填双方生日可解锁五行合参"

**不能因为缺生日就阻断占卜主流程**，这是体验底线。
